# Trasovník (RouteMaker)

Trasovník (RouteMaker) pomáhá s tvorbou, měřením a stahováním vlastních map a tras pomocí map [Leaflet](https://leafletjs.com/).

Aplikace vznikla pro potřeby projektu [Cestou Vysočiny](https://www.stoky.cz/cestou-vysociny/a-1388) a koordinátorů cestovního ruchu v kraji Vysočina.

Aplikaci si můžete vyzkoušet zde: https://trasovnik.mareska.xyz/

![Náhled](docs/images/preview.png)

## Technologie

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Leaflet](https://leafletjs.com/) + [react-leaflet](https://react-leaflet.js.org/)
- [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- [Vite](https://vite.dev/)

## Vývoj

```bash
npm install
npm run dev
```

## Sestavení

```bash
npm run build
```
